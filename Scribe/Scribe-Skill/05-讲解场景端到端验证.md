# 文档 05｜讲解场景端到端验证

> 阶段 S5：把「讲解 RTDL → 存技能 → 复用」在仿真里跑通，验证完整闭环。

## 阶段目标

构造一个讲解类 RTDL（导航到展点序列 + 讲解/语音 + 相机快照），首次执行成功后落技能；再次问「带我去讲解」时命中技能，先「移动至初始位置」再按流程执行；量化复用收益。

## 依赖（前置）

- S1–S4 全部完成。

## 具体子任务

### 5.1 构造讲解 RTDL
- 用 `sequence` 组织：导航到展点 1 → `speak`（讲解）→ 相机快照 → 导航到展点 2 → … → 回到起点。
- 能力：`capabilities/service/speech/speak.v1.toml`、相机快照、导航。

### 5.2 首次执行并落技能
- 首次执行成功 → S1 落结构化计划 → S2 提炼技能 → S3/S4 注册可复用。

### 5.3 复用验证
- 再次问「带我去讲解」（相同/相似问法）：
  - 断言命中技能，RTDL 首节点为「移动到初始位置」。
  - 断言按既有流程执行，无需 LLM 逐步推导。

### 5.4 量化收益
- 记录并对比：从零规划 vs 技能复用 的 RTDL 轮次、token 消耗、wall-clock。

## 所需资源/工具

- Webots 仿真（现有 T1 环境）、`rbnx boot`
- Pilot / Executor、speech、camera、navigation 能力

## 预期交付物

- 可复现 demo + 截图/终端记录 + 收益对比数据。

## 时间节点（可选）
