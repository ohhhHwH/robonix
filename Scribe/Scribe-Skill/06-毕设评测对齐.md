### 6.1 定义技能复用指标
- 规划步数 / RTDL 轮次（复用 vs 从零）。
- Token 消耗（1 次 tool call vs 多轮推导）。
- 执行成功率（技能复用与重放一致性）。
- 冷启动成本（首次无技能时的规划开销）。

### 6.2 基线对比与消融
- 基线（对齐文档「基线方法」）：No-Memory / Vec-Store / ScribeMem-BM25+Embed / ScribeMem-LLM-Search / **ScribeMem-Full（含技能）**。
- 消融：有技能 vs 无技能（同检索但无 refine）对比，突出技能复用增益。

### 6.3 统计与论文落地
- 统计方法：Bootstrap / McNemar / 效应量（Cohen's d），复用 ScribeMem-Bench 评测框架。
